IThis guide covers Play Integrity troubleshooting for Integrity Box

Fixing Play Integrity

This guide is only about Play Integrity. It does not provide root hiding, app security bypass, or methods to bypass an app's own security checks. Results depend on your device, ROM, keybox, Google services, and Google's current checks.

Custom ROM users

1. Disable the ROM's built-in spoofing

If you use a custom ROM. Some ROMs apply their own device-property or Play Store spoofing, which overrides Integrity Box's pixel spoofing. It is recommended to disable the ROM's built-in spoofing before proceeding. IntegrityBox disables it by default.

  1. Open your ROM settings.
  2. Look under Miscellaneous ↝ Spoofing or a similar Play Integrity menu.
  3. If the option exists, disable the ROM's built-in spoofing.
  4. If there is no such option, open Integrity Box WebUI ↝ ROM Spoofing ↝ You will see total 4 options there.
  5. SelectDisable Device Spoofing and Disable PlayStore Spoofing.
  6. Reboot your device to apply changes.
Recommended module setup

2. Remove existing modules, then install the recommended setup

Make sure to remove all installed modules before proceeding. They can interfere with Keybox, target scope, and spoofing, breaking module functionality. Keep your setup minimal for now to avoid wasting time troubleshooting. You can reinstall the modules later once you’ve achieved your goal.

Zygiskless mode

If you use a Google Pixel stock ROM, or intentionally want to keep your custom ROM's own spoofing implementation, Integrity Box can run without its Zygisk-related components. Before flashing Integrity Box, create a file or folder named zygisk directly in internal storage at /sdcard/zygisk. The name must be lowercase. Integrity Box will then disable its Zygisk-related components, helping avoid overlap with the ROM's own implementation.

Important: Use Zygiskless mode only when you deliberately do not want Integrity Box's Zygisk components. It is not a general-purpose fix for every device. Otherwise, choose one supported option from the Zygisk group above.

Configure Integrity Box before rebooting

After flashing Integrity Box for the first time, do not reboot immediately. Open your root manager's Modules section, launch Integrity Box WebUI, and complete the first-install configuration. Reboot only after setup is complete. Read the description if you need help understanding a setting.

Verify before changing more settings

3. Check Play Integrity in the Play Store

Third-party checker apps shows incorrect and misleading results. Use the Google Play Store's built-in checker as your primary reference.

↗ Open Google Play Store
  1. Open the Google Play Store using the button above, or open it from your app drawer.
  2. Go to Settings ↝ About.
  3. Tap Play Store version repeatedly to enable Developer Options.
  4. Go back to Settings ↝ General ↝ Developer Options.
  5. Tap Check Integrity and read the result.

If Developer Options do not appear, make sure the Play Store is up to date and repeat the steps.

Built-in tool

5. Try Repair Mode

If the keybox status looks valid but the Play Store check still fails, use Integrity Box's built-in Repair Mode before changing unrelated settings. It is a targeted troubleshooting step, which works most of the time, however it's not guaranteed that every cause can be fixed automatically.

1

Open Integrity Box WebUI

Launch it from your root manager. Magisk users needs the install KSU WebUI app.

2

Open Repair Mode

Go to Repair Mode ↝ Repair and follow the instructions shown by the WebUI.

3

Check Attestation

After the repair finishes, check key attestation app. It should display Bootloader Is Locked. Use the Play Store's Check Integrity option again.

If the result does not change, continue with the checks below.

Play Store certification

6. If PlayStore says “Device Not Certified”

Play Integrity results and Play Protect certification are different checks. If the Play Store says the device is not certified, check the message it displays and work through the likely cause.

Bootloader or custom ROM

An unlocked bootloader or custom ROM may affect certification. Do not lock your bootloader as a quick fix: locking it on an unsupported setup can make the device unbootable. Only follow your device and ROM maintainer's official instructions.

Root detection

Play Protect may detect a modified system. Review your root setup and any modules that modify Google services or system properties. Remove conflicting changes and test again.

Outdated security patch

Check whether an official system update is available. Integrity Box also has patch-spoofing options, but the project README warns that patch spoofing can cause issues on some stock ROMs. Do not change it unless you understand the risk and have a recovery plan.

Google Play Services is updating

If the error appeared during a Play Services update, wait for the update to finish, reboot if needed, and check again before changing your setup.

Certification errors can have different causes. Read the exact message instead of assuming every “Not certified” error has the same fix.

1

Check your device fingerprint

A banned or broken fingerprint can cause failures. In Integrity Box WebUI, go to Set Profile and try a supported profile such as PIXELIFY or SUPREME, and test again.

Stock ROM: check patch spoofing

On some stock ROMs, Play Integrity may still fail even when the rest of the setup looks correct because your Android system security patch is too old. In Integrity Box WebUI, open Module Settings,and disable Skip Patch Spoofing, and reboot your device.

Patch spoofing can cause issues on some OEM ROMs, That is why it comes disabled by default on stock ROMs.Do this at your own risk. If the change causes problems, simply revert it.

Module settings reference

Use this screenshot to locate the skip patch spoofing feature in WebUI.

2

Look for conflicting modules

Temporarily disable other modules that affect Google Play Services, the Play Store, Zygisk, or device properties. Test with the recommended setup before adding anything else.

3

Check SELinux status

Integrity Box's dashboard can show the SELinux status. The project recommends ENFORCING mode. If it is PERMISSIVE, consider whether your ROM supports enforcing mode before changing anything.

Advanced setting warning: the project includes a Spoof SELinux option under WebUI ↝ Module Settings, but the README warns that it may cause boot issues. Do not enable it casually. If you already enabled it and the device cannot boot, the project README says to remove /data/adb/Box-Brain/spoof-selinux-boot from recovery.
4

Consider a recent Google Play Services update

If the problem began immediately after an update, check whether the update has completed. The project README also suggests testing after uninstalling Play Services updates where Android provides that option, but this is not guaranteed to help.

5

Clear Play Store data only when needed

If you are starting over with a clean setup, clear Google Play Store data and reboot. You do not need to keep clearing data after every small change.

6

Change one thing at a time

After each change, reboot if required (WebUI shows a toast messege) and check the result again. If you change several settings at once, it becomes much harder to know what actually helped.
